# Contributing to Embeejayz Rewards

Before contributing, read our [rules for contributing](./RULES_FOR_CONTRIBUTING.md) to understand the project's expectations and guidelines.

## Getting Started

1. Fork the repository and clone it to your local machine.
2. Create a new branch for your changes.
3. Make your changes and commit them with descriptive commit messages.
4. Push your changes to your forked repository.
5. Create a pull request to the main repository.

## Code Style

We use ESLint and Prettier to enforce code style. Please make sure your code adheres to the style guide before submitting a pull request.

## Commit Messages

We use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) to generate changelogs and release notes and the extension [Conventional Commits](https://marketplace.visualstudio.com/items?itemName=vivaxy.vscode-conventional-commits) for VSCode. Please follow the guidelines outlined in the extension to ensure your commit messages are in the correct format.

## Pull Requests

When submitting a pull request, please include a clear and concise description of the changes made. If your pull request is related to an issue, please reference the issue number in your commit message or pull request description.
